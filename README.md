# DeenHub — دين هب

تطبيق إسلامي شامل باللغة العربية (RTL) مبني بـ Flutter و Material 3، مع دعم الوضع الداكن.

## المبدأ المعماري الأساسي

**لا يُكتب أي محتوى إسلامي داخل واجهة المستخدم مباشرة.**

كل وحدة محتوى (قرآن، تفسير، حديث، مكتبة، أذكار، مواقيت) تمر عبر طبقات:

```
UI (Screens) → Repository (interface) → DataSource (interface)
                                          ├── Remote (HTTP API)
                                          ├── Asset (JSON محلي)
                                          ├── SQLite
                                          └── Cache
```

وكل عنصر محتوى يحمل معلومات الإسناد عبر `ContentSource`:
`sourceName` · `authorOrScholar` · `reference` · `sourceUrl` · `lastUpdated`

## هيكل المشروع

```
lib/
├── core/            # السمات، الثوابت، التوجيه (Routing)
├── models/          # نماذج البيانات مع معلومات الإسناد
├── data/
│   ├── datasources/ # واجهات مصادر البيانات المجردة (6)
│   └── repositories/# واجهات المستودعات (6)
├── services/        # ApiClient (HTTP) · CacheService · AssetDataLoader
├── screens/         # شاشات التطبيق (15)
├── widgets/         # مكونات واجهة مشتركة
├── providers/       # إدارة الحالة (الإعدادات، المفضلة)
└── assets_data/     # ملفات JSON للمحتوى المحلي
```

## وحدة القرآن الكريم (مكتملة)

أول وحدة مطبَّقة بالكامل وفق المعمارية:

- **`RemoteQuranDataSource`** — واجهة Quran.com الرسمية (v4): قائمة السور،
  الآيات (نص عثماني مع الجزء والصفحة)، والبحث.
- **`LocalQuranDataSource`** — النص العثماني الكامل (مشروع Tanzil، رواية
  حفص) مضمَّن كملفات JSON في `lib/assets_data/quran/` فيعمل التطبيق
  دون اتصال، مع بحث عربي يتجاهل التشكيل وعلامات المصحف.
- **`QuranRepositoryImpl`** — يفضّل المصدر البعيد مع مهلة، ويعود تلقائياً
  إلى المصدر المحلي عند انقطاع الاتصال، مع ذاكرة مؤقتة داخل الجلسة.

الميزات: قائمة السور · قراءة السورة بخط أميري مع البسملة · البحث
(بعيد/محلي) · مفضلة الآيات · حفظ موضع آخر قراءة · نسخ ومشاركة الآية
مع الإسناد الكامل للمصدر.

## وحدة التفسير (مكتملة)

كتب التفسير الخمسة كلها متصلة بمصادر رسمية حقيقية:

| الكتاب | المصدر البعيد |
|---|---|
| تفسير السعدي | Quran.com API v4 (id 91) |
| تفسير ابن كثير | Quran.com API v4 (id 14) |
| تفسير الطبري | Quran.com API v4 (id 15) |
| تفسير القرطبي | Quran.com API v4 (id 90) |
| تفسير الجلالين | AlQuran Cloud API (ar.jalalayn) |

- **`RemoteTafsirDataSource`** (Quran.com) و **`AlQuranCloudTafsirDataSource`**
  (الجلالين) — مع تنظيف نصوص HTML والإسناد الكامل.
- **`LocalTafsirDataSource`** — سجل الكتب المعتمد + عينات حقيقية من
  تفسير السعدي مضمَّنة كاحتياطي دون اتصال، مع بحث عربي يتجاهل التشكيل.
- **`TafsirRepositoryImpl`** — ذاكرة الجلسة ← الذاكرة الدائمة (دون
  اتصال، TTL ٣٠ يوماً عبر `CacheService`) ← المصادر البعيدة بالترتيب ←
  الملفات المحلية.

الميزات: «عرض التفسير» من أي آية · تبديل فوري بين الكتب (جلب مسبق
بالتوازي) · بحث داخل نص التفسير مع إبراز يتجاهل التشكيل · بحث في
نصوص التفسير المحفوظة · إشارات مرجعية لصفحات التفسير · مقاطع مفضلة ·
بطاقة إسناد كاملة (الكتاب، العالِم، المصدر، المرجع، الرابط).

## وحدة الحديث الشريف (مكتملة)

المصادر (بترتيب الأولوية، مصادر رسمية فقط):

| الدور | المصدر | الحالة |
|---|---|---|
| المجموعات الكلاسيكية | Sunnah.com API | جاهز — يتفعل عند تهيئة مفتاح API |
| البحث مع الدرجة والمحدِّث | الدرر السنية (dorar.net) | متصل |
| التصفح والنصوص (ع/EN) | موسوعة الأحاديث النبوية (HadeethEnc.com) | متصل |
| دون اتصال | عينة حقيقية مضمَّنة من الموسوعة | متصل |

- **النماذج**: `HadithBookModel`، `HadithChapterModel`، `HadithModel`،
  `HadithSearchResultModel` — كلها بإسناد `ContentSource` كامل.
- **`HadithRepositoryImpl`**: ذاكرة الجلسة ← الذاكرة الدائمة (الأحاديث
  المفتوحة تُخزن ٣٠ يوماً وتُقرأ دون اتصال) ← المصادر البعيدة بالترتيب
  (تُتخطى غير المهيأة) ← الملفات المحلية. البحث: الدرر أولاً ثم محلي.

الميزات: تصفح الكتب والأبواب · فتح الحديث بنصه العربي والإنجليزي ·
الراوي · الدرجة · الشرح · بطاقة إسناد كاملة (المصدر، الكتاب، رقم
الحديث، الدرجة، الرابط) · نسخ ومشاركة · مفضلة · متابعة آخر حديث ·
بحث عربي يتجاهل التشكيل (النص، الراوي، الباب).

## وحدة مواقيت الصلاة والقبلة (مكتملة)

- **`RemotePrayerDataSource`** — واجهة AlAdhan الرسمية: المواقيت الستة
  والتاريخ الهجري بالعربية، بطرق حساب: أم القرى (افتراضي)، رابطة
  العالم الإسلامي، الهيئة المصرية، ديانت التركية، ISNA.
- **`LocalPrayerCacheDataSource`** — آخر مواقيت ناجحة لكل (موقع،
  طريقة) في الذاكرة الدائمة؛ عند انقطاع الاتصال تُعرض مع تحذير.
- **الموقع** — geolocator مع اختيار يدوي من ٣٥ مدينة عند رفض الإذن،
  وتُحفظ المدينة محلياً.
- **`QiblaService`** — حساب محلي لاتجاه القبلة (زاوية الدائرة العظمى
  نحو الكعبة) يعمل دون اتصال — النتائج مطابقة لواجهة AlAdhan الرسمية.
- **التذكيرات** — بنية `PrayerNotificationService` جاهزة مع مفاتيح
  تفعيل لكل صلاة (التطبيق الفعلي للمنصات لاحقاً).

الشاشات: المواقيت (التاريخان، الصلاة التالية بعدّاد تنازلي حي،
تحذير الذاكرة المحفوظة) · القبلة (قرص بوصلة + الدرجة والمسافة
والإرشادات) · إعدادات الصلاة (طريقة الحساب والتذكيرات).
